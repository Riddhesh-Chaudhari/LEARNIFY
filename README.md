# 📚 Learnify — AI-Powered English Learning App

> From Beginner to Intermediate — one quiz at a time.

🔗 **Live Demo:** [https://riddhesh-chaudhari.github.io/learnify](https://riddhesh-chaudhari.github.io/learnify)

---

## ✨ Features

- ✍️ **Vocabulary Quiz** — AI-generated MCQs at Beginner / Elementary / Intermediate level
- 📝 **Grammar Quiz** — Practice Tenses, Articles, Prepositions, Pronouns & more
- 🎤 **Speaking Test** — Record your voice and get AI feedback on fluency & vocabulary
- 📖 **Word Book** — Every new word saved with definition, pronunciation & example
- 📊 **Progress Tracker** — XP system, level-up from Beginner → Intermediate
- 💡 **Word of the Day** — A new word every day with meaning & usage

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Structure | HTML5 |
| Styling | CSS3 (Grid, Flexbox) |
| Logic | Vanilla JavaScript (ES6+) |
| AI | Google Gemini API (`gemini-3.8-flash`) |
| Speech | Web Speech API |
| Storage | localStorage |

---

## 🚀 How to Run Locally

1. Clone the repo:
   ```bash
   git clone https://github.com/Riddhesh-Chaudhari/learnify.git
   ```
2. Open `index.html` in **Google Chrome**
3. Get a free API key from [aistudio.google.com](https://aistudio.google.com/app/apikey)
4. Paste it in the app → Start learning!
